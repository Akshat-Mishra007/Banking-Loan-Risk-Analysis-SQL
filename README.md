# Banking-Loan-Risk-Analysis-SQL
SQL-based analysis of loan portfolio, borrower characteristics, and loan default risk using MySQL


## Project Overview
This project analyzes a loan portfolio using MySQL to understand borrower characteristics, loan distribution, and loan default risk.

## Objectives
- Analyze the total number and amount of loans.
- Calculate the overall loan default rate.
- Compare default rates across borrower categories.
- Analyze loan purposes and credit score categories.
- Identify patterns that may help understand loan default risk.

## Tools Used
- MySQL
- MySQL Workbench
- SQL

## SQL Concepts Covered
- SELECT, WHERE, ORDER BY
- Aggregate Functions: COUNT, SUM, AVG
- GROUP BY and HAVING
- CASE Statements
- Subqueries
- Common Table Expressions (CTEs)
- JOINs
- Window Functions

## Project Questions
The project includes 16 business-oriented SQL questions covering loan portfolio analysis and default risk.

## Key Findings
Key findings will be added after validating the results of all 16 SQL queries.

## Conclusion
This project demonstrates how SQL can be used to analyze loan data, compare default rates, and generate business insights to support risk analysis.
